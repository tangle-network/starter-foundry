# KYC Onboarding Starter
This starter is derived from 5× real demand signal and is designed to provide a basic structure for KYC onboarding applications.
## Taxonomy
* Language: TypeScript
* Runtime: Node
* Surface: Frontend
## Getting Started
To get started with this starter, please follow these steps:
1. Install the required dependencies by running `npm install` or `yarn install` in your terminal.
2. Start the development server by running `npm run dev` or `yarn dev`.
3. Open your web browser and navigate to `http://localhost:3000` to view the application.
## Agent-Facing Extension Guide
This starter also provides a basic structure for agent-facing extensions. To create an extension, please follow these steps:
1. Create a new file in the `src` directory and add your extension code.
2. Import the required dependencies and register your extension with the application.
3. Start the development server and test your extension.
