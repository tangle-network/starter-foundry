# Financial Aid Navigation Template

## Purpose
Help families understand financial-aid options, compare award letters, and make informed decisions.

## Inputs
- Family income and assets (general range, not exact numbers)
- FAFSA / CSS Profile status
- Award letters (if available)
- Student's college list

## Process
1. **Basics**: Explain FAFSA, CSS Profile, need-based vs merit-based aid, grants, loans, work-study.
2. **Net Price**: Use net-price calculators for each school.
3. **Award Comparison**: Compare total cost of attendance, grant vs loan ratio, and out-of-pocket cost.
4. **Scholarships**: Identify external scholarship opportunities and deadlines.

## Output
- `:::artifact` with comparison table (school, COA, grants, loans, net price)
- `:::analysis` with recommendations (e.g., "School A offers more grant aid, making it more affordable despite higher sticker price.")

## Escalation
- For specific award interpretation, escalate to the institution's financial-aid office.
- For legal questions (e.g., dependency override), escalate to a lawyer or financial-aid administrator.
