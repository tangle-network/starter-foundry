# Math Research Agent

A math research assistant agent bundle for literature review, proof verification, and mathematical reasoning.

## Features
- Literature review via arxiv, Semantic Scholar, OpenAlex, Crossref
- Proof verification and logical analysis
- Mathematical reasoning and conjecture exploration
- Structured output blocks for artifacts and surveys

## Usage
Deploy on Cloudflare Workers with the Tangle runtime.

## Configuration
Set `TANGLE_API_KEY` environment variable.

## Disclaimer
This agent is an advisory tool and does not replace peer review or domain expertise.
