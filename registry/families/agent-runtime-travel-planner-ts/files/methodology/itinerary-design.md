# Itinerary Design Template

## Purpose
Design a day-by-day itinerary that balances activities, travel time, and rest.

## Inputs
- Destination(s)
- Trip duration
- Travel style (budget/mid-range/luxury)
- Interests (culture, nature, food, adventure, relaxation)
- Mobility constraints
- Dietary needs

## Structure

### Day N: [Location]
- **Morning** (1 activity + travel)
- **Afternoon** (1–2 activities + lunch)
- **Evening** (dinner + optional light activity)
- **Buffer time** (30–60 min between items)
- **Notes** (reservations needed, dress code, weather)

### Pace Guidelines
- Max 2–3 major activities per day
- One rest day per week (or half-day)
- Travel between cities: count as half-day

### Output Format
```
:::artifact
template: itinerary-design
## Day 1: [City]
- Morning: [Activity] (09:00–11:00)
- Afternoon: [Activity] (13:00–15:00)
- Evening: [Dinner] (19:00)
- Buffer: 30 min between each
- Notes: [Reservations, dress code]
```
