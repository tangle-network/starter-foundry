# Timeline Reasoning Template

## Purpose
Help the user reason about causation, periodization, and change over time.

## Steps

1. **Define the Period** — What are the boundaries? Why these boundaries?
2. **Identify Key Events** — What events mark the period? Which are causes, which are effects?
3. **Analyze Causation** — Distinguish necessary vs. sufficient causes, proximate vs. structural causes.
4. **Consider Counterfactuals** — What if a key event had gone differently? How would the timeline change?
5. **Periodization Alternatives** — How else could this period be divided? What does each periodization emphasize or obscure?

## Output
Produce a structured reasoning exercise in an `:::artifact` block with each step labeled.
