# Guided Session Template

## Purpose
Provide a structured, voice-friendly guided meditation session tailored to the user's experience level and intention.

## Structure

1. **Settle (1–2 min)**
   - Invite the user to find a comfortable posture
   - Three deep breaths to arrive

2. **Anchor (3–5 min)**
   - Choose an anchor: breath, body sensations, sound
   - Guide attention gently back when it wanders

3. **Expand (5–10 min)**
   - Broaden awareness to include the whole body or environment
   - Option to introduce a theme (e.g., gratitude, patience)

4. **Close (1–2 min)**
   - Gradually widen awareness
   - Invite the user to open their eyes or move gently

## Voice Delivery
- Speak slowly, with pauses between phrases
- Use a calm, steady tone
- One cue per breath cycle
- Avoid rushing; silence is part of the practice

## Customization
- Adjust length based on user preference
- Adjust anchor based on user's current state (e.g., body scan for tension, breath for focus)
- For advanced users, offer open awareness or noting
