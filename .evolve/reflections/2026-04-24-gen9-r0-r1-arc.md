## Cross-Project Patterns

**P1: The construct-vs-call pattern shipped in two repos within the same arc.**
- agent-eval's `SubprocessSandboxDriver({cwd})` silently dropped → muffled starter-foundry's promoter gate (Gen 8b) AND runtime eval (R0 post-Gen-9).
- Fixed at both layers: starter-foundry bakes cwd at `prepareScaffoldForEval`; agent-eval honors the constructor arg as fallback.
- Cross-project learning: **weakly-typed constructors on classes with richer per-call APIs are a structural footgun**. When the class's primary method takes `config` that shadows the constructor's fields, the constructor arg will be silently dropped unless explicitly read. TypeScript doesn't catch it unless the constructor has a declared no-arg signature.

**P2: macOS tmpdir symlink bites tests that compare paths.**
- Hit twice in this session: Gen 8b behavioral test, R0 new probe test.
- `/var/folders/...` vs `/private/var/folders/...` — bash `pwd` resolves, TypeScript `mkdtempSync` doesn't.
- Fix: always wrap `mkdtempSync(join(tmpdir(), ...))` in `realpathSync(...)` when the path will be compared against subprocess output.
- Cross-project worth: any repo with cross-platform tests that spawn processes in tmp dirs. Should be a lint-helper or test-utility export in agent-eval or a shared internal lib.

**P3: Append-only JSONL logs conflict when both sides append.**
- `.evolve/governor.jsonl`: merge conflict 2x this session. Manual chronological sort + dedup.
- Solution pattern already emerged: `python3 -c` inline script to merge-sort by `ts` field + dedup adjacent identical lines.
- Cross-project worth: all `.evolve/` repos. Worth a 10-line `merge-jsonl-log.mjs` utility.
