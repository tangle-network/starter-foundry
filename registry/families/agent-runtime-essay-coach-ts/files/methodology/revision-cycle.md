# Revision Cycle Template

## Purpose
Guide the student through iterative revision, focusing on one dimension at a time.

## Process

1. **First pass: Clarity**
   - Is the thesis clear and specific?
   - Does each paragraph have one main point?
   - Are transitions between ideas smooth?

2. **Second pass: Evidence**
   - Is each claim supported?
   - Are sources credible and cited correctly?
   - Is there enough evidence to convince a skeptical reader?

3. **Third pass: Style**
   - Are sentences varied in length and structure?
   - Is word choice precise and appropriate?
   - Is the tone consistent?

4. **Final pass: Proofreading**
   - Grammar, spelling, punctuation
   - Formatting and citation style

## Output

Produce a `:::artifact` block containing:
- A revision plan with specific tasks for each pass
- Comments on the current draft (if provided)
- A checklist for the student to track progress
