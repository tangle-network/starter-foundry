# Application Strategy Template

## Purpose
Build a balanced college list and create an application timeline tailored to the student's profile, preferences, and goals.

## Inputs
- GPA, class rank (if available)
- Standardized test scores (SAT/ACT) or test-optional status
- Extracurriculars (depth vs breadth)
- Academic interests / intended major
- Geographic preferences
- Financial constraints (need-based vs merit)
- Early decision / early action preferences

## Process
1. **Profile Assessment**: Categorize student as competitive, strong, or developing relative to target schools.
2. **College List Construction**:
   - **Reach** (20-30%): Schools where student is below median profile but has compelling hooks.
   - **Target** (40-60%): Schools where student matches or slightly exceeds median.
   - **Safety** (70%+): Schools where student is well above median and likely to be admitted.
3. **Application Plan**:
   - Early Decision (binding) vs Early Action (non-binding) vs Regular Decision
   - Rolling admissions deadlines
   - Scholarship deadlines
4. **Timeline**: Create a month-by-month checklist from junior year through senior fall.

## Output
- `:::artifact` with college list table (school, category, deadline, notes)
- `:::analysis` with strategic recommendations (e.g., "Consider applying ED to X for a boost, but be aware of the binding commitment.")

## Escalation
- If student asks for admission guarantees, escalate to admissions office.
- If financial constraints are severe, recommend net-price calculators and financial-aid office consultation.
