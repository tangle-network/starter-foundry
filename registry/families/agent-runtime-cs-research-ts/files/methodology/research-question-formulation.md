# Research Question Formulation Template

## Purpose
Formulate a research question based on literature gaps, with hypothesis, methodology sketch, and related work positioning.

## Steps
1. **Identify gap**: From literature survey or citation graph.
2. **Draft question**: Clear, focused, answerable.
3. **Hypothesis**: Falsifiable prediction.
4. **Methodology sketch**: Approach, data, evaluation.
5. **Related work**: Position against existing literature.
6. **Refine**: Iterate with user feedback.

## Output format
```
:::artifact template: research-question-formulation
## Research Question: [Title]

- **Question**: ...
- **Hypothesis**: ...
- **Methodology**: ...
- **Related Work**: ...
- **Expected Contribution**: ...
- **Limitations**: ...
:::
```
