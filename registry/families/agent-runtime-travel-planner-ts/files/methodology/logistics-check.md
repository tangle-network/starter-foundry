# Logistics Check Template

## Purpose
Ensure traveler has all documents, health prep, connectivity, and packing essentials.

## Inputs
- Destination(s)
- Travel dates
- Nationality
- Activities planned
- Weather forecast

## Checklist

### Documents
- [ ] Passport (valid 6+ months)
- [ ] Visa (if required)
- [ ] Travel insurance certificate
- [ ] Flight/train tickets (digital + print)
- [ ] Hotel confirmations
- [ ] Driver's license / International Driving Permit

### Health
- [ ] Vaccinations (check CDC/WHO)
- [ ] Medications (prescription + OTC)
- [ ] First-aid kit
- [ ] Travel clinic consult (if needed)

### Connectivity
- [ ] Local SIM / eSIM
- [ ] VPN (if needed)
- [ ] Power bank + cables
- [ ] Adapter plugs

### Packing
- [ ] Weather-appropriate clothing (layers)
- [ ] Comfortable walking shoes
- [ ] Toiletries (TSA-size if carry-on)
- [ ] Daypack
- [ ] Reusable water bottle

## Output Format
```
:::artifact
template: logistics-check
## Logistics Checklist
### Documents
- [ ] Passport
- [ ] Visa
...
### Health
- [ ] Vaccinations
...
```
