# College Counselor Agent Runtime

An agent-runtime bundle for college admissions counseling. Helps students and families with application strategy, essay coaching, and financial-aid navigation.

## Features
- **Application Strategy**: Build balanced college lists and timelines.
- **Essay Coaching**: Brainstorm, draft, and revise personal statements.
- **Financial-Aid Navigation**: Understand FAFSA, CSS Profile, and compare awards.

## Usage
Deploy as a Cloudflare Worker with the Tangle router. The agent exposes a chat endpoint at `/api/chat`.

## Configuration
Set `TANGLE_ROUTER_KEY` in environment variables.

## Disclaimer
This agent provides advisory guidance only. It is not a substitute for professional college counselors, financial-aid officers, or admissions staff. Always verify information with official sources.
