# UX Strategy Template

## Overview
Use this template to define a UX strategy for a product or feature. It helps align design decisions with user needs and business goals.

## Sections

### 1. Problem Statement
- What user problem are we solving?
- For whom? (primary persona)
- What is the current experience and its pain points?

### 2. User Goals & Business Goals
- User goals: what does the user want to accomplish?
- Business goals: what does the business need (engagement, conversion, retention)?
- Where do these goals align or conflict?

### 3. Key Scenarios
- List 3–5 key scenarios the design must support.
- For each: user, context, task, success criteria.

### 4. Design Principles
- 3–5 principles that guide decisions (e.g., "progressive disclosure", "error prevention").
- Reference established heuristics where applicable.

### 5. Information Architecture
- High-level structure: screens, navigation, content hierarchy.
- Key user flows (happy path, edge cases).

### 6. Success Metrics
- How will we measure success? (task completion rate, time on task, error rate, satisfaction score)
- Baseline and target values if available.

### 7. Risks & Mitigations
- What could go wrong? (usability issues, technical constraints, adoption barriers)
- How will we mitigate?

## Output
Produce a concise strategy document (1–2 pages) covering the above. Use `:::artifact` block with `template: ux-strategy`.
