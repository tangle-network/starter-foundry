# recruiter-eval-workspace

Generated by `starter-foundry workspace-compose --preset app+agent+eval`.

> App shell + agent runtime + eval harness. Three pnpm packages with env wired so the app talks to the agent and the eval harness benchmarks the agent.

## Bundles

- `app/` — agent-with-ui-ts
- `agent/` — agent-runtime-recruiter-ts
- `eval/` — agent-eval-harness-ts

## Scripts

- `pnpm dev` → `pnpm -r --parallel dev`
- `pnpm build` → `pnpm -r build`
- `pnpm eval` → `pnpm --filter ./eval run eval`
- `pnpm test` → `pnpm -r test`

## Env wiring

Each bundle has its own `.env` populated with placeholder URLs for sibling bundles.
Update them once each service is running locally:

- `app/.env` reads `VITE_AGENT_ENDPOINT` from `agent` (`AGENT_ENDPOINT`)
- `eval/.env` reads `EVAL_TARGET_BASE_URL` from `agent` (`AGENT_ENDPOINT`)
