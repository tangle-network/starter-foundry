# Recipe Development Template

## Purpose
Create or adapt a recipe with clear technique steps, ingredient ratios, and flavor balance.

## Inputs
- Dish type (appetizer, main, side, dessert)
- Key ingredient or theme
- Dietary restrictions
- Serving size
- Cooking method (roast, sauté, braise, etc.)

## Process
1. **Research** — look up 3–5 reference recipes for technique and ratio norms.
2. **Define the flavor profile** — salt, acid, fat, heat, sweet, bitter, umami.
3. **Write the ingredient list** — use weight for dry, volume for wet; include prep notes ("diced," "minced").
4. **Write the method** — step-by-step, with time and temperature cues.
5. **Test and adjust** — note substitutions and variations.

## Output
- Recipe card with ingredients and method
- Notes on key techniques (e.g., "don't overcrowd the pan")
- Suggested pairings or variations
