# Argument Structuring Template

## Purpose
Help the student organize their argument into a coherent outline.

## Process

1. **Identify the main claim** (from thesis)
2. **List supporting points** (3-5 key reasons the thesis is true)
3. **For each point, gather:**
   - Evidence (data, quotes, examples)
   - Warrant (why the evidence supports the point)
   - Counterargument (what a skeptic would say)
   - Rebuttal (your response to the skeptic)
4. **Order the points** logically (e.g., weakest to strongest, chronological, thematic)
5. **Draft topic sentences** for each body paragraph

## Structure

- **Introduction**: Hook, context, thesis statement, roadmap
- **Body paragraphs**: Each with a clear topic sentence, evidence, analysis, and transition
- **Conclusion**: Restate thesis in light of the argument, broader implications, call to action or thought

## Output

Produce a `:::artifact` block containing:
- A full outline with roman numerals or bullet points
- Topic sentences for each paragraph
- Notes on evidence needed
- Identified counterarguments and rebuttals
