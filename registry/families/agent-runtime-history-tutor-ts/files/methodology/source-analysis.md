# Source Analysis Template

## Purpose
Guide the user through systematic analysis of a primary source.

## Steps

1. **Provenance** — Who created it? When? Where? Under what circumstances?
2. **Context** — What was the historical context? What events, ideas, or structures surrounded its creation?
3. **Audience** — Who was the intended audience? How does that shape the content?
4. **Bias & Perspective** — What biases or perspectives are evident? What is left out?
5. **Corroboration** — How does this source compare to other sources from the same period?
6. **Significance** — Why does this source matter? What does it tell us that other sources don't?

## Output
Produce a structured analysis in an `:::artifact` block with each step labeled.
