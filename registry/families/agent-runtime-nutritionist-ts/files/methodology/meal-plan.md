# Meal Plan Template

## Purpose
Generate a structured, flexible meal plan aligned with the user's macro targets, dietary preferences, and lifestyle.

## Inputs
- Daily calorie target
- Macro split (protein, carbs, fat)
- Dietary restrictions (vegetarian, vegan, gluten-free, etc.)
- Food preferences (likes, dislikes)
- Meal frequency (3 meals, 4 meals, etc.)
- Cooking ability and time available

## Process
1. **Calculate per-meal macros** based on meal frequency and total daily targets.
2. **Select food sources** for each macro: lean proteins, whole grains, healthy fats, fruits, vegetables.
3. **Build meals** that are balanced, satisfying, and varied across the week.
4. **Include snacks** if desired, fitting within remaining macros.
5. **Provide alternatives** for each meal to allow flexibility.

## Output
A weekly meal plan with daily breakdowns, including:
- Meal name and description
- Portion sizes (grams, cups, or common measures)
- Macro breakdown per meal
- Total daily macros
- Optional: grocery list

## Constraints
- Do not recommend extreme restriction or elimination of food groups without medical reason.
- Ensure micronutrient adequacy (fiber, vitamins, minerals).
- Avoid foods the user has explicitly ruled out.
- Keep plans realistic for the user's cooking skill and time.
