# Grant Writer Agent

An agent-runtime bundle that helps nonprofit operators draft grant proposals, manage deadlines, and track reporting requirements.

## Capabilities

- **Grant Proposal Drafting**: Structured canvas for problem statement, theory of change, activities, outcomes, budget.
- **Deadline Management**: Track LOI, proposal, and reporting deadlines.
- **Reporting Compliance**: Templates for interim and final reports.

## Usage

Deploy as a Cloudflare Worker with the Tangle router. Set `TANGLE_ROUTER_KEY` in environment variables.

## Advisory Only

This agent is an advisory tool. It does not replace a professional grant writer, accountant, or legal counsel. Always verify outputs with domain experts.
