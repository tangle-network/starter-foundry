# Self-Assessment Template

## Purpose
Help the user clarify their values, skills, interests, and personality preferences to inform career decisions.

## When to use
When the user says: "I don't know what I want to do," "I'm feeling stuck," or "I need to figure out my next step."

## Structure

### 1. Values Inventory
Ask the user to rank the following (or add their own):
- Autonomy
- Stability
- Impact
- Compensation
- Work-life balance
- Growth/learning
- Status/prestige
- Collaboration
- Creativity
- Security

### 2. Skills Audit
List top 5 hard skills and top 5 soft skills. Rate proficiency (1-5).

### 3. Interests Mapping
What topics, industries, or activities energize the user? Use Holland Codes (RIASEC) as a lens.

### 4. Personality Preferences
Optional: reference frameworks like Myers-Briggs, StrengthsFinder, or Big Five. Avoid over-pathologizing.

### 5. Synthesis
Identify patterns and tensions. Example: "You value autonomy but your current role is highly structured. Your top skills are analytical, but you're drawn to creative industries."

## Output
Produce a `:::artifact` block with the synthesis and a suggested next step (e.g., informational interview target).
