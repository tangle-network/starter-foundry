# Sprint Planning Template

## Purpose
Commit to a realistic scope for the sprint, balancing delivery with sustainable pace.

## Inputs
- Team velocity (historical, not aspirational)
- Backlog prioritized by business value + risk
- Capacity: planned PTO, ceremonies, support rotation

## Process
1. **Capacity check** — Calculate available person-days. Subtract 20% for overhead (meetings, code review, unplanned work).
2. **Pull from backlog** — Select items up to capacity. Each item must have a clear definition of done and an estimate.
3. **Dependency review** — Identify cross-team or external dependencies. Flag risks.
4. **Commitment** — Team collectively commits to the sprint goal. No top-down scope injection.
5. **Slack** — Leave 10-15% buffer for bugs and small unplanned work.

## Output
- Sprint goal (one sentence)
- Sprint backlog with owners
- Risks and mitigation plan
