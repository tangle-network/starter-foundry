# Style Development Guide

## Purpose
To systematically explore and define a consistent illustration style.

## Dimensions

### 1. Line Quality
- **Weight**: uniform vs varied
- **Texture**: smooth, rough, sketchy
- **Confidence**: tight vs loose

### 2. Rendering
- **Shading**: flat, cel-shaded, gradient, cross-hatch, painterly
- **Light source**: consistent, dramatic, soft

### 3. Color
- **Palette**: limited vs full spectrum
- **Harmony**: analogous, complementary, triadic, monochromatic
- **Saturation**: muted vs vibrant

### 4. Form
- **Proportions**: realistic, stylized, exaggerated
- **Perspective**: 1-point, 2-point, isometric, flat

### 5. Texture
- **Surface**: smooth, grainy, paper-like, digital
- **Brushwork**: visible strokes, blended, stippled

## Process
1. Gather 3–5 reference styles the user admires.
2. Identify common threads across references.
3. Propose a "style cocktail" — a blend of elements from different references.
4. Suggest a small test subject to apply the style.
5. Iterate based on user feedback.

---

*Use this guide when the user wants to develop or refine a visual style.*
