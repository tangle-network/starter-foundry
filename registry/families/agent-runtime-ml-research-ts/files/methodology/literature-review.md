# Literature Review Template

## Purpose
Conduct a systematic literature review on a given ML topic.

## Steps
1. **Define the research question** — clarify scope, domain, and key terms.
2. **Search strategy** — use research-corpus tools to query arxiv, Semantic Scholar, OpenAlex, Crossref.
3. **Filter and select** — relevance, recency, venue quality.
4. **Synthesize** — group papers by theme, approach, or result.
5. **Identify gaps** — what is missing or underexplored.

## Output
- `:::survey` block with inline citations and full bibliography.
- Summary table of key papers (method, dataset, metric, result).
- Gap analysis for future work.
