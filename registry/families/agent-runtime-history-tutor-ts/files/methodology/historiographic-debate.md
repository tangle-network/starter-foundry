# Historiographic Debate Template

## Purpose
Present a historical debate fairly, naming the major schools and their key claims.

## Steps

1. **Identify the Question** — What historical question is being debated?
2. **Map the Positions** — List the major interpretive schools or historians, their core arguments, and key evidence.
3. **Evaluate Strengths & Weaknesses** — For each position, note its strengths and weaknesses.
4. **Synthesis** — Where is there common ground? What questions remain open?
5. **Further Reading** — Recommend key works for each position.

## Output
Produce a structured summary in an `:::artifact` block with each step labeled.
