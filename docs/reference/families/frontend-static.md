# Family: `frontend-static`

Runnable static frontend starter with instant preview.

**Taxonomy**: language=javascript · runtime=node · surface=frontend

**Tags**: frontend, preview

## When to use

Pure static landing page served by `serve` (no framework). Use when the product is truly a marketing landing page or a static doc site — NOT for apps with state.

## First moves

- Edit `index.html` and `app.js` directly. No build step; `serve -l 3000` is all you need.
- Brand strings: inline in `index.html`. Palette: inline `<style>` or separate `.css`.

## Placeholders (agent MUST replace)

- `index.html` — Default landing with generic hero/feature/CTA blocks. Replace ALL content for the product — the default is placeholder-only.
- `app.js` — Optional interactivity entry. If the landing is truly static, delete the file + its script tag.
