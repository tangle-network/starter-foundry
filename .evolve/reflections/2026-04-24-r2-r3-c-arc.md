## Cross-Project Patterns

**P1 — Lying-metric cluster.**
Two instances in this arc:
- R2: `proposal_promotion_rate` polluted by test-fixture events (108 of 114 "failures" were tests)
- C: `cost-summary.json` always `{}` because `.getSummary?.()` silent-failed and `.record()` never called

Both fit the muffled-gate pattern (Gen 9) but in the *measurement* layer rather than the *gate* layer. A gate that silently passes = bad proposals ship. A metric that silently reports zeros/empties = team optimizes against noise.

**Worth naming explicitly.** Propose adding `.evolve/patterns/lying-metric.md` as a sibling to `muffled-gate.md`. Same shape (something that should fail loud returns silent success), different location (measurement vs gating).

**P2 — Optional-chain method typo as silent-fail.**
`costTracker.getSummary?.() ?? {}` — the typo on method name + optional chain + nullish coalesce form a three-layer sound-suppressor. TypeScript catches neither at compile time (runtime-dispatched) nor at runtime (optional-chain silently returns undefined → default fires).

Sub-shape of muffled-gate pattern. Candidate addition to the invariant scanner:
- Pattern: `\w+\.\w+\?\.\(\)\s*\?\?\s*\{\}` on an assignment/write path
- False positives: any `.someMethod?.()` that's legitimately optional for backward-compat. Need case-by-case muffle-ok annotations.

**P3 — Operator-override-when-I-hedge.**
Two instances same session (R1 "just do it", this-arc "do C, then B"). Both times I was about to defer; both times there was real work within reach. Memory entry worth: when governor/reflect want to dispatch `/reflect` or `/stop` against a RED flow with un-probed local data, probe one layer deeper before deferring.
