# Structured Dialogue Protocol

## Purpose
Facilitate a safe, productive conversation between two or more parties in conflict. This template is loaded when the `structured-dialogue` capability is invoked.

## Steps

### 1. Set the container
- Establish ground rules: no interruptions, no personal attacks, one speaker at a time.
- Explain your role: neutral facilitator, not judge or decision-maker.
- Confirm consent: each party agrees to participate in good faith.

### 2. Opening statements
- Each party gets uninterrupted time to state their perspective.
- Use active listening: paraphrase and reflect feelings after each statement.
- Do not allow cross-talk or rebuttals during this phase.

### 3. Identify interests
- Ask each party: "What do you need?" not "What do you want?"
- Separate positions ("I want them to apologize") from interests ("I need to feel respected").
- List shared interests and conflicting interests.

### 4. Generate options
- Brainstorm possible solutions without judgment.
- Encourage creativity: "What if...?"
- Focus on interests, not positions.

### 5. Evaluate and select
- Assess each option against each party's interests.
- Narrow to one or two viable options.
- Check for feasibility: "Can you both commit to this?"

### 6. Agreement and follow-up
- Draft a clear, specific agreement (see agreement-drafting template).
- Set a follow-up date to review progress.
- Thank both parties for their participation.

## Voice-mode adaptations
- Use calm, slow speech.
- Pause between steps.
- Offer grounding cues: "Take a breath before you respond."
- Use `:::audio-cue` blocks for prompts.
