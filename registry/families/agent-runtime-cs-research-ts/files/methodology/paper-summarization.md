# Paper Summarization Template

## Purpose
Summarize a single paper concisely: problem, method, key result, limitations.

## Steps
1. **Retrieve**: Fetch the paper via research-corpus tools.
2. **Read**: Extract abstract, introduction, method, results, conclusion.
3. **Summarize**: Write a structured summary.
4. **Cite**: Provide full citation.

## Output format
```
:::artifact template: paper-summarization
## Summary: [Title]

- **Authors**: ...
- **Venue**: ...
- **Year**: ...
- **Problem**: ...
- **Method**: ...
- **Key Result**: ...
- **Limitations**: ...
- **Relevance**: ...

### Full Citation
[surname, year] Title. Venue. URL
:::
```
