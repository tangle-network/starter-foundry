# Demo Script Template

## Purpose
Build a structured demo script that maps to the prospect's use case, not a generic product tour.

## Sections

### 1. Discovery Summary
- Prospect name, role, company
- Primary use case / pain point
- Technical environment (stack, scale, constraints)
- Decision criteria and timeline
- Evaluation team members and their roles

### 2. Demo Flow
| Step | Duration | Narrative | Key Feature | Success Signal |
|------|----------|-----------|-------------|----------------|
| 1 | 2 min | Context: "We understand you're dealing with X..." | N/A | Nodding / verbal agreement |
| 2 | 5 min | Show how product solves the primary pain point | Feature A | "Can you show that again?" |
| 3 | 3 min | Address secondary concern | Feature B | "How does this handle Y?" |
| 4 | 2 min | Recap and next steps | N/A | "Let's set up a POC" |

### 3. Objection Handling
- Anticipated objection 1: Prepare response with evidence
- Anticipated objection 2: Prepare response with evidence

### 4. Technical Deep-Dive (if needed)
- Architecture diagram walkthrough
- API / integration points
- Performance benchmarks
- Security / compliance highlights

### 5. Next Steps
- POC proposal
- Technical documentation
- Follow-up meeting with engineering team
