# Player Loop Design Template

## Overview
Use this template to design a player loop — the core cycle of action, feedback, and progression that defines the player's moment-to-moment experience.

## Fields

- **Loop Name**: Short, descriptive name.
- **Loop Type**: Core loop (primary) or secondary loop (supporting).
- **Action**: What the player does (e.g., explore, fight, gather, craft).
- **Feedback**: What the player receives (e.g., loot, XP, story progression).
- **Progression**: How the loop evolves over time (e.g., harder enemies, new abilities).
- **Duration**: Typical time for one iteration.
- **Motivation**: Intrinsic (autonomy, competence, relatedness) and extrinsic (rewards).
- **Metric**: How you would measure engagement (e.g., session length, loop completion rate).
- **Trade-offs**: What this loop costs in terms of other loops or design goals.

## Example

- **Loop Name**: Combat Loop
- **Loop Type**: Core loop
- **Action**: Engage enemies using weapons and abilities.
- **Feedback**: Enemy defeat yields XP, loot, and story progression.
- **Progression**: Enemies scale in difficulty; player unlocks new abilities and gear.
- **Duration**: 30 seconds to 2 minutes per encounter.
- **Motivation**: Competence (mastering combat), autonomy (choosing tactics), extrinsic (loot).
- **Metric**: Encounters per session; player retention after first combat.
- **Trade-offs**: Combat-heavy loops may alienate narrative-focused players.
