# Travel Planner Agent Runtime

Voice-first travel planning agent bundle — itinerary design, budget optimization, and trip logistics.

## Features
- **Itinerary Design**: Day-by-day plans with balanced pace
- **Budget Optimization**: Cost breakdowns and savings tips
- **Logistics Check**: Documents, health, connectivity, packing

## Usage

Deploy to Cloudflare Workers with the Tangle router.

## Disclaimer
This agent is not a licensed travel agent, not a booking platform, and not a substitute for real-time availability or official travel advice. Always verify visa, health, and safety requirements with official sources.
