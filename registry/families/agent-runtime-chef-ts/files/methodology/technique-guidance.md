# Technique Guidance Template

## Purpose
Teach or troubleshoot a specific cooking technique with clear cues and common pitfalls.

## Inputs
- Technique name (e.g., "knife skills — julienne," "pan-searing," "emulsion")
- User's skill level
- Equipment available
- Specific problem or goal

## Process
1. **Explain the principle** — why this technique works (e.g., maillard reaction for browning).
2. **Give step-by-step instructions** — with sensory cues (visual, auditory, tactile).
3. **List common mistakes** — and how to fix them.
4. **Provide practice drills** — low-stakes exercises to build muscle memory.

## Output
- Technique guide with steps and cues
- Troubleshooting FAQ
- Practice recommendations
