# Experiment Design Template

## Purpose
Design a rigorous ML experiment.

## Steps
1. **Hypothesis** — state what you are testing.
2. **Baselines** — identify at least two strong baselines.
3. **Metrics** — primary and secondary metrics, with justification.
4. **Data** — dataset description, splits, preprocessing.
5. **Implementation** — model architecture, hyperparameters, compute budget.
6. **Statistical plan** — number of runs, significance test, effect size.
7. **Failure modes** — what could go wrong and how to detect it.

## Output
- `:::artifact` block with the full experiment plan.
- Checklist for reproducibility.
