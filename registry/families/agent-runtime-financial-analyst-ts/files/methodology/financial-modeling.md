# Financial Modeling Template

## Purpose
Build a three-statement financial model (income statement, balance sheet, cash flow) with a DCF valuation.

## Steps
1. **Gather historical data** — at least 3 years of annual financials (10-K) or quarterly (10-Q).
2. **Project revenue** — top-down (TAM * share) or bottom-up (units * price). State the driver.
3. **Project expenses** — COGS as % of revenue, operating expenses by function (R&D, S&M, G&A).
4. **Build the balance sheet** — working capital assumptions (DSO, DIO, DPO), capex as % of revenue.
5. **Build the cash flow statement** — start with net income, adjust for non-cash items and working capital changes.
6. **DCF valuation** — project FCF for 5-10 years, calculate terminal value (Gordon Growth or Exit Multiple), discount by WACC.
7. **Sensitivity analysis** — show how valuation changes with WACC and terminal growth rate.

## Output
- A structured model with clear assumptions and outputs.
- Sensitivity table (WACC vs. terminal growth).
- Key metrics: implied equity value, EV/EBITDA, P/E.

## Refusal
Do not build a model without at least 3 years of historical data. If the user cannot provide it, ask for it or decline.
