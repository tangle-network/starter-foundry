# Grant Reporting Template

## 1. Executive Summary
- Brief overview of progress during the reporting period.

## 2. Activities Completed
- List activities funded by the grant.
- Include dates, locations, participant numbers.

## 3. Outcomes Achieved
- Compare against stated outcomes in the proposal.
- Use quantitative data where possible.
- Include qualitative stories or testimonials.

## 4. Challenges & Lessons Learned
- What didn't go as planned?
- How did you adapt?
- What would you do differently?

## 5. Financial Report
- Budget vs actual expenditures.
- Explain any significant variances.
- Attach receipts or invoices as required.

## 6. Next Steps
- Plans for the next reporting period.
- Any changes to timeline or activities.

---
*Customize sections based on funder requirements. Attach supporting documents as needed.*
