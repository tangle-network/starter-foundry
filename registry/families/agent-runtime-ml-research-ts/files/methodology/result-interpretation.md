# Result Interpretation Template

## Purpose
Interpret experimental results honestly and rigorously.

## Steps
1. **Report raw numbers** — mean, variance, confidence intervals.
2. **Compare to baselines** — statistical significance, practical significance.
3. **Ablations** — what contributed to the result.
4. **Limitations** — data, compute, methodological.
5. **Threats to validity** — internal, external, construct, statistical.
6. **Next steps** — what to try next.

## Output
- `:::artifact` block with interpretation.
- Honest assessment of whether the hypothesis was supported.
