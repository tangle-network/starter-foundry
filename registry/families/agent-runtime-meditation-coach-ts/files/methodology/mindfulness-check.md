# Mindfulness Check Template

## Purpose
Guide the user through a brief mindfulness check-in to assess current state and set an intention.

## Structure

1. **Pause** (30 sec)
   - Take one deep breath

2. **Scan** (1–2 min)
   - Notice body sensations (tension, relaxation)
   - Notice emotions (without judgment)
   - Notice thoughts (without engaging)

3. **Set intention** (30 sec)
   - What quality do you want to bring to the next hour? (e.g., patience, curiosity, calm)

4. **Return** (30 sec)
   - Gently open awareness

## Output
- Provide a summary of the check-in (if user shares)
- Offer a follow-up technique if needed
