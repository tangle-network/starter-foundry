# Engineering Manager Agent Runtime

An advisory agent for engineering managers: 1:1 cadence, sprint planning, incident post-mortems, and tech-debt triage.

## Usage

Deploy as a Cloudflare Worker. Set `TANGLE_ROUTER_KEY` environment variable.

## Capabilities

- **1:1 Cadence** — Structured weekly conversations with direct reports.
- **Sprint Planning** — Realistic scope commitment with capacity checks.
- **Incident Post-Mortem** — Blameless, systemic root-cause analysis.
- **Tech Debt Triage** — Prioritize by impact-to-value ratio.

## Advisory Only

This agent provides structured guidance and templates. It does not make personnel decisions, compensation changes, or legal judgments. Always consult your HR, legal, and management chain for high-stakes actions.
